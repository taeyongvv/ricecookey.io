개인정보처리방침

검토용 초안 · 작성일: 2026년 9월 14일 · 미시행

공개 전 확인이 필요한 초안입니다. 서버 데이터의 보유·파기 기준, 법령에 따른 권리 행사 절차, 만 13세 이용자를 포함하는 서비스의 개인정보 처리 요건을 운영자가 확인한 뒤 시행일을 정해야 합니다. 이 문서는 해당 요건의 충족을 보증하지 않습니다.

Rice Cookey(이하 “운영자”)의 Android 게임 귤리의 파티쉐:2048(패키지명 com.ricecookey.berritz2048)에서 처리되는 정보와 현재 제공되는 기능을 설명합니다.

1. 계정과 랭킹

게임은 이메일·비밀번호를 입력하는 회원가입이나 이메일 로그인을 제공하지 않습니다. 대신 Unity Gaming Services(UGS) Authentication이 익명 인증용 플레이어 ID를 자동으로 생성합니다. 익명 인증은 이름을 입력하지 않는 방식이며, 식별정보를 전혀 처리하지 않는다는 뜻은 아닙니다.

  • 플레이어 ID: 플레이어 인증과 랭킹 기록 연결에 사용합니다.
  • 닉네임: 이용자가 선택적으로 입력·변경하는 표시 이름을 Unity Authentication에 저장하고 랭킹에 표시합니다. 실명, 연락처 등 개인정보를 닉네임에 넣지 마세요.
  • 점수·게임 모드: 게임 종료 시 모드별 점수를 Unity Leaderboards에 전송하여 순위를 산정합니다. 랭킹의 표시 이름, 점수, 순위는 다른 이용자가 볼 수 있습니다.

2. 기기에 저장하는 정보와 게임 분석

선택한 모드, 모드별 최고 점수, 음량 등 게임 설정은 기기 저장소에 저장됩니다. 최고 점수의 기기 저장과 서버 랭킹 기록은 별개입니다.

게임에는 Unity Analytics 6.3.0과 게임 시작·종료 이벤트 기록 코드가 포함되어 있습니다. 종료 이벤트의 항목은 게임 모드, 격자 크기, 최종 점수, 최고 점수, 플레이 시간이며, 목적은 게임 이용 현황 분석과 품질 개선입니다.

분석 수집 상태: 현재 확인한 코드만으로는 Analytics의 수집 개시·동의 상태와 실제 서버 전송 여부를 확정하지 못했습니다. 따라서 게임 이벤트가 항상 전송된다고 하거나 분석 수집이 전혀 없다고 단정하지 않습니다.

3. 광고 SDK가 처리하는 정보

게임은 Google AdMob의 배너 광고와 이용자가 선택하여 시청하는 보상형 광고를 사용합니다. 보상형 광고를 선택하지 않더라도 SDK 초기화·광고 사전 로드·배너 광고 과정에서 데이터가 처리될 수 있습니다.

Google Mobile Ads Android SDK 25.4.0의 공식 고지에 따르면 다음 정보가 광고 제공, 분석, 부정행위 방지를 위해 자동으로 수집·공유됩니다.

  • IP 주소와 대략적인 위치: 기기의 IP 주소를 수집하며 이를 통해 일반적인 위치를 추정할 수 있습니다.
  • 앱·광고 상호작용: 앱 실행, 탭, 동영상 시청 등 이용 정보입니다.
  • 진단·성능 정보: 앱과 SDK의 실행 시간, 멈춤 비율, 에너지 사용량 등 오류·성능 관련 정보입니다. SDK의 진단 처리 범위에는 충돌·오류 관련 정보가 포함될 수 있습니다.
  • 기기·계정 관련 식별자: Android 광고 ID, 앱 세트 ID 및 해당되는 경우 기기에 로그인된 계정 관련 식별자입니다. 이는 게임이 이메일 로그인을 제공한다는 뜻은 아닙니다.

Android 설정의 광고 ID 관리 기능에서 광고 ID를 재설정하거나 삭제할 수 있습니다. 설정 경로는 기기·OS에 따라 다릅니다. 광고 ID 삭제가 모든 광고 데이터 수집을 중단하거나 이미 저장된 게임·광고 기록을 삭제하는 것은 아닙니다.

Google Mobile Ads SDK 데이터 공개 안내 · Google 파트너 서비스의 정보 이용 안내

4. 외부 서비스와 정보 처리

  • Unity Gaming Services: 익명 인증, 표시 이름, 모드별 랭킹과 게임 분석 기능에 사용합니다. Unity 개인정보처리방침
  • Google AdMob: 위에 설명한 광고·기기·이용 정보를 처리합니다. Google 개인정보처리방침
  • 개인정보 문의: 이메일을 보내는 경우 회신 주소와 이용자가 적은 문의 내용을 Gmail을 통해 수신합니다. 게임에서 이메일 로그인을 받는 것과는 별개입니다.
  • 이 정책 페이지: GitHub Pages가 호스팅하며 접속 요청 정보를 처리할 수 있습니다. 사이트의 기존 스타일시트가 사용하는 글꼴은 jsDelivr에서 불러오므로 글꼴 요청 시 IP 주소 등 통신 정보가 전달될 수 있습니다. 이 페이지에는 별도의 방문 분석 스크립트를 넣지 않습니다. GitHub 개인정보 안내 · jsDelivr 개인정보 안내

외부 제공자의 서비스 이용 과정에서 정보가 대한민국 밖에서 처리될 수 있습니다. 구체적인 처리 지역, 이전 조건과 보존 설정은 공개 전에 확인할 사항입니다. 외부 제공자의 정책 링크는 운영자가 확인해야 할 사항을 대신하지 않습니다.

5. 보유 기간과 삭제의 범위

공개 전 확인 필요: UGS의 플레이어 ID·닉네임·랭킹, 분석·광고 정보, 이메일 문의 각각의 실제 보존 설정과 운영자의 파기 기준은 아직 확정·검증되지 않았습니다. 확인되지 않은 보유 기간이나 서비스 종료 시 자동 파기를 약속하지 않습니다.

기기 저장소의 기록과 서버의 기록은 별개입니다. 앱 삭제나 기기 데이터 초기화만으로 Unity 또는 Google이 처리한 서버 데이터까지 삭제되는 것은 아닙니다. 기기 백업·복원 동작에 따라 기기 기록의 잔존·복원 여부도 달라질 수 있습니다.

6. 이용자의 선택과 개인정보 권리

닉네임은 게임의 닉네임 변경 화면에서 수정할 수 있습니다. 현재 게임에는 익명 계정이나 서버 랭킹 기록의 삭제를 요청하는 인앱 기능 또는 별도의 계정 삭제 요청 기능이 구현되어 있지 않으며, 운영자가 제공하는 이메일 삭제 요청 서비스도 없습니다.

아래 이메일은 일반 개인정보 문의용입니다. 이메일을 보내면 계정·랭킹·분석·광고 기록을 삭제해 드린다고 약속하는 연락처가 아닙니다.

이러한 기능의 부재는 관련 법령에 따라 이용자에게 인정되는 열람·정정·삭제·처리정지 등의 권리를 포기시키거나 제한한다는 뜻이 아닙니다. 법령상 권리를 행사할 수 있는 실제 절차와 필요한 운영 조치는 공개 전에 별도로 확인해야 합니다.

7. 이용 연령

게임의 대상 이용 연령은 만 13세 이상입니다. 이는 만 14세 미만 이용자의 정보가 수집되지 않는다는 뜻이 아니며, 만 13세 이용자도 위의 익명 인증·랭킹·SDK 데이터 처리 대상이 될 수 있습니다.

연령 표기만으로 법정대리인 동의 등 지역별 아동·청소년 개인정보 보호 요건의 충족이 확인되는 것은 아닙니다. 해당 연령에 적용되는 요건과 실제 동의·광고 처리 방식을 공개 전에 검토해야 합니다.

8. 방침 변경과 문의

시행되는 방침의 변경 내용과 날짜는 이 페이지에 표시합니다. 현재 문서는 검토용 초안이며 시행일이 정해지지 않았습니다.
